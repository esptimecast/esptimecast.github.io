Privacy Policy for ESPTimeCast Browser Extension

Overview

ESPTimeCast Browser Extension does not collect, store, or share personal user data.
The extension only communicates with devices explicitly configured by the user.

Data Usage

The extension accesses limited website content solely to extract media information such as:
	•	Video titles
	•	Song titles
	•	Artist names

This data is used only to display currently playing media on a user-owned ESPTimeCast device.

Data Storage

No user data is stored locally or remotely by the extension.

Data Sharing

The extension does not transmit data to any external servers.
All communication occurs միայն between the browser and user-configured devices on the local network.

Personal Information

The extension does not collect:
	•	Personally identifiable information
	•	Authentication data
	•	Financial or health data
	•	Location data
	•	Browsing history

Third Parties

No data is shared with third parties.

Security

All data processing is performed locally within the user’s browser.

Changes

This policy may be updated in the future. Any changes will be reflected on this page.
